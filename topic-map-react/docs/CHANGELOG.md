# Changelog

This changelog records documentation and implementation observations from the source archive supplied for review. It is not a complete historical development log.

## Source snapshot reviewed

- Application: Topic Maps React App
- Frontend: React 19 and TypeScript
- Build tool: Vite 8 beta
- Graph library: React Flow 11
- Subject maps: 10
- Topic records: 128 in the supplied source snapshot

## Features present in the reviewed source

- Navigation across ten A-Level Mathematics subject maps.
- Searchable alphabetical topic sidebar.
- Interactive dependency graph.
- Focus and Full map display modes.
- Topic detail panel with optional summary, specification reference, prerequisites, successor topics, and external learning link.
- Circular-dependency detection and warning.
- Firebase-backed feedback scripts referenced from the HTML entry page.
